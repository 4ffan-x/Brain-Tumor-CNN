# Brain-Tumor-CNN
"Brain Tumor Classification using CNN - This project classifies brain MRI images into tumor types (glioma, meningioma, no tumor, pituitary) with a CNN. It covers data preprocessing, model training, and evaluation using ROC curves and confusion matrices, culminating in an image inference system."
